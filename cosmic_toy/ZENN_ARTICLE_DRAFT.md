# 【Python】閉じた玩具宇宙で、重力だけ・時間の矢・循環を「示唆」として眺める

> **この記事で言えること**: 2 次元・軟化ニュートン・散逸なしの**玩具宇宙**で、保存量・相関・巻き戻し誤差を測った結果の**示唆**です。  
> **言わないこと**: 宇宙論の証明、「宇宙の正体が判明した」、現実の宇宙にそのまま当てはまる断定。[^tone]

逆円周率ノイズのマトリクス実験（[前編：逆πは本当に SA を救うか](https://zenn.dev/cocoa3j21/articles/b72a764450e23a)）とは別系統で、**「閉じた系で重力だけ動かすと何が見えるか」** を数値で追いました。AI エージェントとスクリプトを組み直し、`leapfrog` 可逆積分で Q1〜Q5 を一気に回しています。

- コード（公開）: [github.com/cocoa3j21/inverse-pi-optimizer/tree/main/cosmic_toy](https://github.com/cocoa3j21/inverse-pi-optimizer/tree/main/cosmic_toy)
- 代表図: リポジトリ内 `cosmic_toy/figures/cosmic_collapse_time_arrow.png`（6 パネル要約）
- フルログ: 開発正本 [Labs/cosmic_toy @ ai-budget-meter](https://github.com/cocoa3j21/ai-budget-meter/tree/master/Labs/cosmic_toy)（巨大 CSV は手元再実行用）

## 玩具のルール

| 項目 | 設定 |
| --- | --- |
| 次元 | 2D |
| 相互作用 | Plummer 軟化ニュートン自己重力（**放射・散逸なし**） |
| 積分 | leapfrog (KDK) — **時間可逆** |
| 粒子数 | N=200、ステップ 3000、`dt=0.005` |
| 条件 | `bound_collapse` / `expanding` / `marginal` / `reflecting_wall` / `time_reversed` |
| シード | 5 条件 × 5 シード = 25 ラン |

「閉じた宇宙」は周期境界ではなく、**外力ゼロ・エネルギー保存の孤立系**（＋壁反射の対照）として定義しています。[^closed]

エントロピーは位相空間の粗視化そのものではなく、**格子ベースの代理指標**（箱・形状・速度）です。定義を変えると向きも変わります。[^entropy]

## Q1. 重力だけで、ほぼ一様な系は凝縮するか

**示唆**: はい——ただし **コア側に強く**、ハローは後から開き得ます。

- 重心半径 `R_gyr` 最小/初期 ≈ **0.250 ± 0.032**
- 20% 質量半径（コア）最小/初期 ≈ **0.173 ± 0.029**
- 同一ランでハローは最大 **約 4.2 倍**まで膨張するケースあり（負の比熱っぽい二相）
- `expanding` / `marginal` ではコア収縮はほぼ **1.0**（起きない）

コアとハローで物語が分かれるので、「全体サイズだけ見ると膨張した」とも読めます。指標の選び方が語りを決めます。[^q1]

---

## Q2. 凝縮は「ビッグバン直後」に似るか

**示唆**: 本データでは **「似る／似ない」のどちらも裁定しにくい**。

エントロピー代理の終始差（bound、5 シード平均）:

| 代理 | Δ（nats） |
| --- | --- |
| box | **−1.15 ± 0.17** |
| shape | **−0.61 ± 0.31** |
| speed | **+2.53 ± 0.06** |

3 種が同じ向きに揃わず、教科書的な「凝縮 → エントロピー単調増加」は**明確には再現しませんでした**。初期を一様＝低エントロピーとみなすのは**実験設計側の仮定**です。[^q2]

---

## Q3. 時間の矢を「収縮方向」に読むと何が変わるか

**示唆**: **物理量は変わらない**。変わるのは「単調に見えるか」だけ。

- 実時間の box エントロピー「単調増加」割合 ≈ **0.47**
- `R_gyr` の増加順・減少順に**並べ替えても** multiset は同一 → 割合は ≈ **0.50 / 0.50** 付近
- `expanding` では実時間 **0.27** → 収縮向きラベルだと **0.73** に見え方が反転

ここが **解釈実験** の核心です。時間の矢を逆に**読む**ことと、時空が逆に**動く**ことは別物です。[^tone]

---

## Q4. 循環するか、一方向に終わるか

**示唆**:

- 初期マクロ状態への「最接近距離」: bound **2.45 ± 0.07**、壁付き **2.40 ± 0.06** → **明確な差は出ない**
- 膨張条件は最終的に **10〜27 倍**級まで一方向に開く
- 壁のバウンス（平均 **約 14 回**）と、粗視化エントロピーの不可逆性は**別物として測っている**

サイズが振動しても、今回の粗いマクロ指標だけでは「きれいな周期宇宙」とは言いづらい——というのが正直な読みです。[^q4]

## Q5. 過去に戻れるか — 速度反転とラベル反転

### Q5-A 速度反転（物理操作）

- なめらかな孤立系: 戻り誤差 rms/R₀ 最大 **〜1.4×10⁻¹²**（丸め誤差級）→ **可逆 integrator 上の巻き戻しとして読める**（宇宙論の「過去に戻った」断定ではない）[^q5a]
- 反射壁あり: 最大 **〜0.20** まで誤差増幅 — 不連続衝突の影響の**示唆**

### Q5-B ラベル反転（解釈操作）

系列を逆順に読んでも物理量の集合は **完全一致**。変わるのは時間との相関の**符号**（例: box の Spearman **−0.43 → +0.43**）。

**主張しないこと**: 「時空が逆方向に動く」という物理的断定。[^q5b]

### おまけ: `time_reversed` 条件

人工的に中間状態から速度反転した系は、マクロ距離 **〜0.11** まで初期付近に戻る——**系列を往復した設計上の話**であり、現実宇宙の言い換えにはなりません。[^q5tr]

## 数値の信頼性（一言で）

相対エネルギー漂移は bound で最大 **〜0.09%** 程度。可逆 integrator 上の Q5-A と矛盾しません。[^reliability]

## おわりに

「重力だけ・閉じた系・有限時間」という**かなり理想化した箱**の中では、

- 凝縮は起きるが **コアとハローで物語が割れる**
- エントロピー代理は **ビッグバン像との類比を急がせない**
- 時間の矢は **ラベルの貼り方で見え方が変わる**
- 巻き戻しは **積分の可逆性と壁の不連続性で分かれる**

——という **示唆の束** が手元に残りました。宇宙の正体ではなく、**測り方と解釈の癖**を並べたメモだと思って読んでもらえると嬉しいです。
